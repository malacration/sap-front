O código anterior também continua valendo por mais uma janela.

Como usar

Quando uma operação fica barrada por uma regra (desconto acima do limite, custo, depósito, etc.), esta tela gera um código temporário que libera aquela operação uma vez.

Passo a passo:

  1. Escolha a regra que está barrando a operação.
  2. Clique em Gerar código. Vai aparecer um código de 6 caracteres.
  3. Use Copiar código e passe para quem está com o documento barrado.
  4. No documento barrado (pedido, nota, entrega…), essa pessoa digita o código no campo “Código de liberação” e salva de novo. A operação passa.

Importante:

  • O código muda a cada ~2 minutos. Se demorar, gere um novo (o anterior ainda vale por um tempinho).
  • Cada regra tem seu próprio código: um código de “Desconto” não libera “Custo”.
  • Gere o código só na hora de usar e passe apenas para quem precisa — é uma autorização.
  • Se aparecer “sem permissão”, seu usuário não pode gerar código; fale com um gestor.
